# 开放边界

现在还开着什么、记在哪。这份是活的索引，跟着现状改；带日期的记录（`docs/NN-*.md`）只记当时，正文不改。

- **关上一条**：收口写在原话的标题底下（那一节末尾的引用块），同时把它从这里删掉。
- **写一份新的记录**：它记「当时没关上的」那几节（仍然开着的边界、没量到的、没能验证的项、没做的、不做的与仍然开着的、本轮新登记的已知边界），
  逐节在 §3 登一行。一节全关上了，那一行留着、写明关在哪。`tests/open-index.test.mjs` 钉着：docs/15 起每一节都要在这里点到，点到的都要指得到。
- **只管点到与指得到**：每一条是不是真的还开着，判据不读，靠关上它的人顺手删。条目标「（有意）」的是当时就决定接受的边界，不是待修项。

截至 2026-10-10（v3.9.0，`docs/58`）。逐条的来历与证据看指向的那一节；这里每条一句话。
