# 引用截断留头留尾

> 2026-10-10，M4v，分支 `m4v-quote-keeps-tail`。第十五轮，从 `docs/00-开放边界.md` §3 挑的：`docs/27` §4「`quote` 截到 80 或 120 个字符，Windows 上的长路径
> 只剩开头」。正文是复核修订之后的样子，复核与改了什么在 §8。

## 0. 一句话结论

- `quote`（门禁把外部值拼进回传、拒绝理由与留痕时用的那一个）原来太长的只留开头：异常消息的末尾正好是出错的文件路径，长路径的最后一段正好是文件名，
  这两样都被截掉。现在截成「头…尾」：头占上限的三分之二，尾占剩下的，一共上限那么多个码点再加一个「…」。

## 1. 修法

- `hooks/lib/trusted.mjs` 的 `clip`：不长于上限的原样；长的按码点取头（上限的三分之二，向上取整）与尾（剩下的），中间放「…」。`quote` 与退到 `quote`
  的 `inline` 都走它。受信前缀在截之前已经消去，头尾中间隔着「…」，拼不回一个前缀；引号、转义、行分隔符的处理都在截之后，照旧。
- 不是字符串的值（数组、对象）截过之后，整段当成字符串再加一次引号：它的 JSON 写法截过就不是合法 JSON 了，留尾时尾巴可能从某个字符串的中间开始，
  里面的话落到引号外面（复核 §8 的中 1）。没截的照旧原样输出它的 JSON 写法（数字与字符串分得出来）。
- 两份判据的写法跟着改：`tests/gate-completion.test.mjs` 的「截断」不再要求「…」紧贴收尾的引号；`tests/trusted-echo.test.mjs` 里项目根带载荷的那一格，
  POSIX 上改在短的 `/tmp` 下建（macOS 的 tmpdir 本身就很长，目录名会落进被截掉的中间），正向锚点认载荷的标签、或者目录名紧跟着载荷的第一个字
  （证明载荷经过了 `quote`），不回显的几条照旧逐条核。

## 2. 判据与变异

- `tests/trusted.test.mjs`：异常消息里的文件名留得下，开头的错误种类也在；头的长度钉住（默认上限 54、120 时 80）、一共上限再加一个「…」；默认上限
  同样留尾；正好上限的原样、多一个才截，码元超上限、码点不超的原样；表情放在开头、末尾、两头，两个切点都不劈开代理对；长数组截过之后，各种切分长度
  下载荷都不出引号。

变异（备份在仓库外，改完逐字节还原）各红：只留头（原来的样子）；只留尾；头少尾多；尾按码元切；不标截断；多留一个；不长的也截；复核修订之后补的刀在 §8。

## 3. 实测

- 没起真实会话：`quote` 是纯函数，判据直接测它，门禁各处的用法不变。
- 分支 CI 的结果写在合并之后的收口里。
  > **收口（M4w，2026-10-10，`docs/58`）**：分支第一次推（`f398019`）macOS 两格红（§8），复核修订 `f48595c` 推上去之后 ci 三个系统与 min-node 全绿；合并
  > （`16a4bca`，v3.8.0）之后 main 上 ci 的判据（三个系统、Node 22 与 24）、版本检查、tag 作业与 min-node 全绿，tag 作业打了 `v3.8.0`、建了它的 Release。

## 4. 仍然开着的边界

- **中间那一截看不到**：一个很长的值，要紧的那一段正好在中间时照样被截掉（例如长路径里的项目目录名——macOS 的临时目录下尤其如此，分支 CI 就撞上了，§8）。
- **截过的数组、对象看不出类型**：整段成了一个字符串（为了让里面的话出不了引号）。
- **上限没改**：80 与 120 照旧；更长的上限会让回传变长，没有实测过多长算合适。

## 5. 没量到的

- 真实会话里带长路径的拒绝理由、【门禁】回传，项目经理读不读得懂截过的那一段。

## 8. 复核与修订

`f398019` 推上去之后两件事：分支 CI 在 macOS 上红了一格；一路对抗复核（变异在仓库里备份还原、逐字节核过）。字符串值：截在加引号之前、按码点切，
转义切不开、不产生孤立代理项，行分隔符在截之后转义；受信前缀在截之前消去，头尾拼不回来；值里没有换行，门禁标记出不了行首。

- **CI　macOS 上项目根那一格的正向锚点没命中**：macOS 的临时目录（`/private/var/folders/…`）本身就长，头只剩上限的三分之二，载荷的标签与目录名都落进了
  被截掉的中间（§4 那一条的实物）。**改**：那一格在 POSIX 上改到短的 `/tmp` 下建。
- **中 1　不是字符串的值截过之后，载荷能落到引号外面**：数组的 JSON 写法上截，尾巴从第二个字符串的中间开始，只剩收尾的引号；复现里 `project.json` 的
  `paths` 写两个调好长度的元素，拒绝理由与受信块里的那句话就在引号外。原来只留头时留下一个没闭合的引号，也不对，只是开引号看得见；判据里一直没有
  长的非字符串载荷。**改**：截过的整段再加一次引号（§1）；补一条切分长度扫一遍的判据，撤掉这一处的刀打红。
- **低**：
  - 按码元判长短、头向下取整、头取一半加一，三刀存活——钉住头的长度与「码点不超上限的原样」；
  - 项目根那一格只认目录名证明不了载荷经过了 `quote`——改成目录名紧跟着载荷的第一个字。
