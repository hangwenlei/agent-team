# 一趟只归一个会话 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每一趟 run 记下归哪个会话；别的会话写它、切走它、另建一趟、以它的名义派人，门禁拒；别的会话里起 `/agent-team:at` 时项目经理问「是不是补充」、原会话没了用 `/agent-team:at-resume` 明确接手。

**Architecture:** 新的纯函数模块 `hooks/lib/owner.mjs` 定归属记录、判定与文案；`gate.mjs` 只做 I/O：账本在建 run 那一次写 `runs/<id>/owner.json`，H3 与 H2 对主线程调用按它拦，批准记录器认接手的两个标签，一个新的、会说话的 UserPromptExpansion 检查项在命令展开时告诉项目经理。原话记录改成按会话分开记（同一份文件、带版本的表），两个会话不再互相覆盖。

**Tech Stack:** Node（`MIN_NODE` 起），零 npm 依赖，`node --test`。

**Spec:** `docs/superpowers/specs/2026-11-05-边看边改微调与会话归属-design.md`（§5.2、§8 第 1 条）

## Global Constraints

- 零 npm 依赖，不建 `package.json`；`hooks/` 下不用晚于 `MIN_NODE` 的内建（不用 `structuredClone`），boot.mjs 不碰。
- 门禁子进程一律经 `tests/helpers/gate-runner.mjs` 的 `run` 起；判据跑裸 `node --test`。
- 运行时读得到的文字（命令正文、门禁回传与拒绝理由）只写现行规则：不写 docs 编号、里程碑、「上一版」。
- 外部值进回传与拒绝理由：磁盘上的（run id、时间、原话）用 `quote`，调用方这次给的参数（会话 id 不进文字）用 `inline`。
- 特殊字符用 `String.fromCharCode` 构造；锚串替换用 `split/join` 并断言命中数；落盘后扫控制字节与行尾。
- 门禁专属文件的格式变了，同一份磁盘状态不许被改判：没有 `owner.json` 的 run 一切照旧；旧的单份 `user-words.json` 照旧认。
- 发版：`plugin.json` 挪到 `7.8.0`，`CHANGELOG.md` 最上面加一行；先推功能分支、CI 全绿再合 main。
- 规范标签逐字（单一真源 `hooks/lib/owner.mjs`）：`是，回那个会话补充`、`不是，结束这次`、`在这个会话接手`、`接手并收口，再开始这次`、`回那个会话`。

## Review Focus

1. hook 输入里没有 `session_id`（旧 CLI、SDK 宿主）：不记归属、不拦，留一行痕；行为与今天相同。→ Task 2、3 的判据。
2. `owner.json` 被手改坏、截断：当没有归属（放行、留痕）；H3 照旧拒改它。→ Task 1、3 的判据。
3. run 是用 Bash 建的（门禁没见到建的那一次）：没有归属，行为与今天相同。→ Task 2 的判据。
4. `current-run` 与目录名大小写不同（Windows、macOS）：认成同一趟。→ Task 3 的判据（经 `norm` 比）。
5. 两个会话几乎同时展开命令：原话记录两份都在（锁）。→ Task 5 的判据。

## Rulings 预置（执行时照抄进账本）

- 完整一趟的「放弃」收尾挪到第二步：没有微调时它不改变任何行为（设计 §8 第 1 条把它排在第一步）。
- 归属在账本（PostToolUse）记，认「建 run」用 H6 同一个口径：run 目录里还没有任何门禁专属文件（`GATE_FILES`）。代价：升级前建的、还停在第一段、一份门禁专属文件都没有的 run，下一次被写时归给写它的会话。
- 只管主线程（项目经理或不带 `agent_type` 的主会话，且不带 `agent_id`）；子代理照旧按派发记录认。
- 对没有归属记录的 run 选「在这个会话接手」也记（给它补上归属）。

  - `ownerRecord({ sessionId, at, via, previous = null }) → { session_id, at, via, previous }`，`via ∈ {'create','takeover'}`。
  - `readOwner(bytes) → { session_id, at, via, previous } | null`：不是对象、`session_id` 不是非空字符串、`via` 不在两个值里 → null。

  - `ownerDenyReason(block) → string`。
  - `takeoverAnswer(toolResponse) → null | { label } | { why }`。
  - `sessionNotice({ command, runId, startedAt, wordsHead, delivered, via }) → string`，`command ∈ {'at','at-resume','at-status'}`。
  - `takeoverNotice({ runId, why }) → string`（`why` 为 null 是记下了）。
