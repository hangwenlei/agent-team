# 并行微调 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 同一个项目目录里多个会话各跑一趟微调；门禁按会话与 `agent_id` 认这一次属于哪一趟、两个微调不改同一个文件、微调与完整的一趟互斥，并给完整的一趟与微调一个由门禁认的「放弃」收尾。

**Architecture:** 微调不再写 `current-run`。门禁每一次先「挑这一趟」（`hooks/lib/runpick.mjs`）：子代理按派发记录认回派它的那一趟微调，主线程按会话认它名下没收口的那一趟微调，都不是就照旧按 `current-run`；gate.mjs 里每一处读运行上下文都经 `runCtxFor(input)`。互斥在 H6 建 run 那一次判（`hooks/lib/parallel.mjs`），认领文件记在每一趟自己的 `runs/<id>/claims.jsonl`（`hooks/lib/claims.mjs`），放弃是一次带 `abandoned: true` 的收口、要用户经规范标签批准（`hooks/lib/abandon.mjs`）。

**Tech Stack:** Node（`MIN_NODE` 起），零 npm 依赖，`node --test`。

**Spec:** `docs/superpowers/specs/2026-11-05-边看边改微调与会话归属-design.md`（§5.6 并行、§5.7 放弃与卡住、§5.8 没走过完整一趟的项目、§7 验证）；第一步 `docs/103`、第二步 `docs/104` 的裁定照旧成立。

## Global Constraints

- 零 npm 依赖，不建 `package.json`；`hooks/` 不用晚于 `MIN_NODE` 的内建；`boot.mjs` 不动。
- 运行时正文（角色、命令、模板、门禁回传与拒绝理由）只写现行规则，不写 docs 编号、里程碑、「上一版」；`docs/` 之外不写裁定编号；列举，不报总数。
- 外部值进回传按来源引：磁盘上的值（run id、原话、路径、时间）过 `quote`；调用方这次给的参数与由项目根拼出的路径用 `inline`。
- 门禁专属文件加一份就进 `hooks/lib/control-files.mjs` 的 `GATE_FILES`（H3 对任何人的 Edit/Write 都拒）。
- 门禁专属文件的算法或格式变了，不许让同一份磁盘状态被改判：没有 `mode`、没有归属记录、没有认领记录的 run，门禁的每一个判定与今天相同（现有判据全绿就是那份「上一版状态的夹具」）。
- 规范标签放进单一真源（这一步新加的在 `abandon.mjs`），正文与判据从那里取。
- 发版：插件会加载的东西变了，挪中间一位——7.9.0 的中间一位不能长到 10，进位成 **8.0.0**；`CHANGELOG.md` 最上面加一行。
- 门禁的回传与拒绝理由一律中文；跑测试用裸 `node --test`；写带特殊字符的脚本用写文件工具，`String.fromCharCode` 造特殊字符。

## Review Focus

1. 团队角色的子代理、哪一趟的派发记录里都查不到、`current-run` 不在、项目里只有微调——照今天的口径是 no-run、H3 全放行。期望：开着微调时这样的写入**拒**（认不出它是哪一趟派的，叫它冒泡），不让一次没记下的派发把认领与写路径隔离一起绕开。→ Task 1 的判据。
2. 一趟微调放弃或收口之后，它派出去的子代理还在跑、接着写文件。期望：按派发记录仍认回那一趟（不落到 `current-run` 或 no-run），照那一趟判写路径；认领只看没收尾的微调。→ Task 1（按 `agent_id` 认时连已收尾的微调一起找）。
3. 主线程的 hook 输入里读不到会话 id。期望：照 `current-run` 判，并往 stderr 留一行「读不到会话 id、按 current-run 判」——不静默。→ Task 1。
4. 同一个文件的两种写法（`src/a.ts` 与 `src/./a.ts`，Windows、macOS 上还有大小写）。期望：认成同一个文件、照样拒。→ Task 3（认领键是 `norm()` 之后的绝对路径）。
5. 两个会话各有一趟微调，A 会话的项目经理去写 B 会话那一趟的契约或 `state.json`。期望：会话归属那一道照旧拒。→ Task 1 的判据。
